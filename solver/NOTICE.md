Aetherform uses the headless geometry code in Proteus (Solona and contributors), with the envelope and long-coat improvements in Kaldigo’s fork. The solver is distributed under AGPL-3.0-or-later. Its license and upstream notices are included in the release archive. The integration assembly is named Proteus.Refit for access to the headless API. Aetherform does not initialize the Proteus plugin, register its commands, or write its configuration.

The [pinned engine source](https://github.com/kaldigo/FFXIVAetherform/blob/main/vendor/proteus/proteus-11a0b095.zip) corresponds to release v2611.1659.0.6. Extract it and check out these dependencies into the named directories before following the included build instructions.
